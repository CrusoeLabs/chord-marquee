# Changelog

All notable changes to Chord Marquee are documented here.

## [0.1.0] - 2026-10-07

### Added

- Current chord, next chord, and beat-countdown displays in Ableton Live's
  Device View.
- Large resizable floating chord window with a Window/Close toggle.
- Event-driven Live API observers for track, clip, and Arrangement-loop edits.
- Manual Refresh control for reconnecting to the `CHORDS` track.
- Loop-aware wrapping from the last chord in an active loop to the chord at the
  loop start.
- Frozen, self-contained `.amxd` release packaging.
